Avocado Price Analysis

Does price move volume? Which regions and varieties lead U.S. avocado sales? Answered in PostgreSQL.

Case description

Weekly Hass avocado sales data, 2015 to 2018: average price, total volume, and volume by PLU code (small, large, extra-large), across U.S. regions. Loaded into PostgreSQL and queried directly. This rebuilds a project I studied where the original repository had gone offline, using a different, real, obtainable dataset covering the same questions.

Does price actually move volume?

The obvious hypothesis for any priced product: raise the price, sales drop. Worth testing before assuming it, because if the relationship is weak, pricing isn't the lever to pull.

Query

SELECT CORR(average_price, total_volume) AS price_volume_correlation
FROM avocado_prices
WHERE region <> 'TotalUS';

-0.34. Price and volume move in opposite directions, but weakly. Something else, promotions, seasonality, competing produce, is doing more work than price alone. Pricing changes shouldn't be sold internally as a guaranteed volume lever.

Which regions carry the volume?

Not every region buys the same. Knowing where volume concentrates changes where a distribution or marketing budget should go first.

Query

SELECT region, SUM(total_volume) AS total_volume_2015_2018
FROM avocado_prices
WHERE region <> 'TotalUS'
GROUP BY region ORDER BY total_volume_2015_2018 DESC LIMIT 10;

West, California, and SouthCentral lead, within 7% of each other. No single region dominates the way Bikes dominates the SQL EDA sales data, this is a genuinely distributed demand base, which lowers regional concentration risk.

Which size variety actually sells?

If a supplier assumes small avocados are the safe default order, the data should back that up before it becomes a purchasing rule.

Query

SELECT 'PLU4046 (small)' AS variety, SUM(plu4046) AS total_volume FROM avocado_prices
UNION ALL SELECT 'PLU4225 (large)', SUM(plu4225) FROM avocado_prices
UNION ALL SELECT 'PLU4770 (extra-large)', SUM(plu4770) FROM avocado_prices
ORDER BY total_volume DESC;

Large Hass (PLU4225) edges out small Hass (PLU4046) by less than 1%, both far ahead of extra-large. That's close enough to call a tie, not a clear default. A supplier ordering only small avocados on the assumption it's the safe bet would be leaving nearly half the market's actual preference on the table.

Does Los Angeles track the national trend, or move on its own?

If a major metro moves independently of the national number, using national trends to plan for it is a mistake.

Query

SELECT sale_year,
    SUM(CASE WHEN region = 'LosAngeles' THEN total_volume END) AS los_angeles_volume,
    SUM(CASE WHEN region = 'TotalUS' THEN total_volume END) AS total_us_volume
FROM avocado_prices
WHERE region IN ('LosAngeles', 'TotalUS')
GROUP BY sale_year ORDER BY sale_year;

LA holds a steady ~8.9% share of national volume across all three full years (2015-2017). It tracks the national trend closely enough that national-level forecasts are a reasonable proxy for LA, no separate regional model needed here.
