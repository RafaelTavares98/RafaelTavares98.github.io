SQL EDA — PostgreSQL

Exploratory data analysis on a sales data warehouse, translated from SQL Server to PostgreSQL 17.

Case Description

This project follows Baraa Khatib Salkini's "sql-data-analytics-project" hands-on portfolio project, an exploratory data analysis exercise over a sales data warehouse. The original scripts target SQL Server; I rebuilt the whole thing on PostgreSQL 17, running locally.

The gold schema holds 3 tables: 18,484 customers, 295 products, and 60,398 sales records.

The analysis is structured around 13 sections, from basic database exploration to two final reporting views:

  • Database and dimension exploration, date ranges, key measures
  • Magnitude and ranking analysis
  • Change over time, cumulative totals, year-over-year performance
  • Customer and product segmentation, part-to-whole analysis
  • Two reporting views: gold.report_customers and gold.report_products

SQL Server → PostgreSQL

Every script needed a real syntax translation, not just a copy-paste. The main changes:

  • DATEDIFF(month, a, b) → a calendar-month difference built from EXTRACT(YEAR ...) and EXTRACT(MONTH ...)
  • GETDATE() → CURRENT_DATE
  • TOP n → ORDER BY ... LIMIT n
  • DATETRUNC() / FORMAT() → DATE_TRUNC() / TO_CHAR()
  • BULK INSERT → COPY ... WITH (FORMAT csv, HEADER true)
  • ROUND() on a 2-argument call needed an explicit cast to numeric, since Postgres only allows the 2-argument form on that type

The full, commented query file runs end to end against a local PostgreSQL 17 install with no errors.
